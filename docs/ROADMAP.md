## MVP（P0–P6）

| 阶段 | 内容 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| **P0 骨架** | monorepo、前端脚手架 + 设计令牌 + 布局外壳、后端 /health、文档、Git | 前后端可启动、可连通；vitest/pytest 各绿 | ✅ |
| **P1 数据与克制核心** | generations/rulesets 种子；生成 type-chart.json 与测试向量；PokéAPI 客户端（超时/重试/缓存/降级）；domain/type_engine；克制相关 API | 克制引擎单测全绿（双属性、免疫、4 倍）；两端同一测试向量结果一致 | ✅ |
| **P2 图鉴与搜索** | sync_pokeapi.py；列表/搜索/详情接口；前端图鉴页；四态渲染；后台管理（同步触发+内容编辑） | 断网可看已同步数据；搜索防抖；空/错/过期状态可见 | ✅ |
| **P3 克制计算器 UI** | 接入引擎、双属性组合、反向查询、属性色板 | 手机与桌面可用，与后端 API 结果一致 | ⏳ |
| **P4 收藏与笔记** | owner_key 接入；收藏/笔记 CRUD；空态与失败回滚 | 刷新后数据仍在；同一浏览器内一致 | || **P5 大师考试 v0** | 题库生成、组卷状态机、评分、错题本、来源展示 | 组卷不重复、答案可溯源、错题完整 | |
| **P6 验收留档** | 响应式与可访问性走查；README/DATA_SOURCES 完善；验收清单 | 对照 PRD 验收表逐项通过 | |
